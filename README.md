# 🚀 10 Desafios Coding

Repositório com a resolução de **10 desafios de programação**, com o objetivo de praticar lógica, algoritmos e fortalecer habilidades como desenvolvedor.

## 📌 Sobre o projeto

Este projeto foi criado para:

- Praticar programação na prática
- Melhorar raciocínio lógico
- Organizar soluções de desafios em um só lugar
- Construir portfólio no GitHub

Cada desafio possui sua própria lógica e solução implementada.
